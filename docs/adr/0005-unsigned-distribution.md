# ADR-0005：MVP 使用无签名便携构建

- 状态：Accepted
- 日期：2026-07-24

## 背景

维护者暂不配置 Windows/macOS 代码签名，希望尽量做到下载后使用。

## 决策

- Windows 发布便携 ZIP；
- macOS 发布应用 ZIP；
- Web/PWA 作为安装摩擦最低的渠道；
- 每个桌面产物附带 SHA-256；
- 不在 MVP 配置代码签名、公证或静默自动更新。

## 已知限制

- Windows/macOS 可能显示未知开发者或安全警告；
- macOS Gatekeeper 可能要求用户额外确认；
- 因此无法保证真正的“一次点击直接运行”；
- 公开面向非技术用户分发时需要重新评估签名。

## 发布要求

- Release Notes 明确说明未签名；
- 在干净 Windows/macOS 设备上验证；
- 不提供降低系统安全设置的自动脚本；
- 不把安全警告描述为应用故障；
- 若未来签名，创建新的 ADR 替代本决策。
